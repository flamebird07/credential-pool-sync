# v7.9.1 endpoint_base_url() 版本剥离修复

## 问题

Feishu 状态栏始终不显示"🔄 周公瑾使用中"，所有记录都是"✅ 正常"。

## 根因

`endpoint_base_url()` 在剥离端点后缀时，把 `/v3` 也一起剥离了。

### 代码追踪

```python
# 健康检查探测到以下端点并成功
_used_url = "https://ark.cn-beijing.volces.com/api/coding/v3/chat/completions"

# endpoint_base_url() 匹配到 "/v3/chat/completions" 整串
# 返回 "https://ark.cn-beijing.volces.com/api/coding"（丢失了 /v3）
healed_url = endpoint_base_url(_used_url)  # → ".../api/coding"

# 原始 Feishu base_url 也是 ".../api/coding"
# 所以 healed_url == bu，愈合不触发
bu = "https://ark.cn-beijing.volces.com/api/coding"
healed_url == bu  # True → 不愈合

# 但 config.yaml 的 base_url 是 ".../api/coding/v3"
# identity 比较永远不匹配
```

### 核心原则

- `endpoint_base_url()` — 只剥离方法后缀，保留版本前缀；用于**愈合**
- `_strip_endpoint_suffix()` — 剥离版本+方法；用于**端点探测**
- 两个函数功能不同，不能混用

### 版本顺序修复

`try_url_variants()` 和 `endpoint_candidates()` 中 `/v3` 优先于 `/v1`。
