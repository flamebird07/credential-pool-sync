# Crash Analysis: 429 Deletion Cascade (from Trae bug report)

**Source**: https://share.traecontent.cn/artifact/LOTKTAMD9C75O-
**Date**: 2026-07-29
**Affected version**: v7.2.0 (pre-fix)

## Crash Timeline

| Time | Event | Detail |
|------|-------|--------|
| T0 | 免费资源包账号 2103691131 触发限流 | 所有 api/v3 端点模型同时返回 429（账号级别"安全体验模式"限流） |
| T1 | sync 脚本执行健康检查 | 6 条免费资源包凭证全部 429，只有火山Agent Plan 通过 |
| T2 | auth.json 被覆盖 | `ex["credential_pool"] = {}` 清空所有凭证，只写入 1 条 |
| T3 | fallback 链缩短 | `sync_fallback_providers()` 排除所有 429 模型，fallback 链从 7 条降至 1 条 |
| T4 | 火山Agent Plan 端点 404 | base_url `api/plan` 缺少 `/v1` 后缀，返回 404 |
| T5 | fallback 链完全耗尽 | 主模型 429 + fallback#1-3 全部 429 + fallback#4 404 = 无可用凭证 |
| T6 | Hermes fallback 到 glm-4.5-air 并持久化 | Z.AI 的 glm-4.5-air 也 429，但被持久化为新主模型 |
| T7 | 人工恢复 | 从飞书重新拉取所有记录，重建 auth.json（9 条），修复 config.yaml，重启 Hermes |

## Root Causes

| Bug | Severity | Root Cause | Fix |
|-----|----------|------------|-----|
| #1 健康检查失败即删除凭证 | CRITICAL | `ex["credential_pool"] = {}` 清空后只写回通过检查的记录；429 是临时限流不应视为永久失效 | `if iv or s == S_R:` 保留 429 记录 |
| #2 fallback 链排除 429 模型 | HIGH | `sync_fallback_providers()` 跳过 429 模型 | 仅跳过 `S_I`（无效），不跳过 `S_R` |
| #3 火山端点 URL 缺少 /v1 | HIGH | `api/plan` → `api/plan/chat/completions` 404；正确应是 `api/plan/v1/chat/completions` | URL 修正 + Provider 反推 + 后端正则清理 |
| #4 自动切换主模型 | MEDIUM | sync 检测到主模型 429 时自动切换 + Hermes 运行时持久化 fallback 模型 | 不再自动切换 |
| #5 多进程冲突 | MEDIUM | 特定时序下启动多个实例，各自缓存不同配置 | 文件锁 + 共享旋转锁 |

## Crash Flow Diagram

```
飞书表格 10 条凭证 → sync 健康检查
  → 6 条 429: 跳过不写入 fe
  → 1 条 OK: 加入 fe 字典
  → 1 条缺字段: 跳过
  → fe 只有 1 条 → auth.json: 9条 → 1条
  → fallback链: 7条 → 1条
  → Hermes fallback: 主模型 429 → fallback #1-3 全部 429 → fallback #4 火山 404
  → 💥 完全崩溃 → 人工恢复
```

## v7.3.0 Fixes Applied

1. Provider Reverse-Inference from Base URL (detect_provider)
2. `repair_feishu_providers()` function (--repair-provider flag)
3. `custom:` prefix removed from credential pool keys
4. All scripts now use detect_provider instead of hardcoded "custom"
5. switch_next.py `_normalise_record()` infers provider from URL
