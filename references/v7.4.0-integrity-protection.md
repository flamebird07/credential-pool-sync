## 修复内容

### Fix 1: 凭证池完整性保护

在 `_sync_unlocked()` 中新增保护逻辑，防止网络故障导致大量凭证被删除：

```python
preserve_existing_pool = (
    old_pool_count > 0
    and new_pool_count < old_pool_count * MIN_POOL_RETENTION_RATIO  # 0.5
    and unavailable_count > checked_count * 0.5  # S_U 占多数
)
```

触发条件：
1. 旧池存在记录
2. 新池 < 旧池 50%
3. 超过一半健康检查返回 S_U（不可用）

触发时保留现有 credential_pool 并输出 WARNING。

### Fix 2: 统一 ARK URL 标准化

提取 `normalise_base_url()` 共享函数，消除 `sync_credential_pool.py` 和 `switch_next.py` 之间的 URL 修正差异。

```python
def normalise_base_url(value):
    base_url = str(value or "").strip().lower().rstrip("/")
    if base_url == "https://ark.cn-beijing.volces.com/api/plan":
        return "https://ark.cn-beijing.volces.com/api/plan/v1"
    return base_url
```

### Fix 3: 注释修正

`sync_fallback_providers()` 注释从"跳过 429 的模型"改为"跳过健康检查确认无效的模型；限流模型仍保留在 fallback 链中"。
